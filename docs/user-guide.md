# 使用指南

本指南面向已连接兼容数据库、能正常登录的 Java 版本。浏览器可打开开发地址 `http://localhost:5173`，或构建后由 Java 提供的 `http://localhost:8080`；同一轮操作请保持使用同一个地址。页面外观仍在与原版对齐，具体文案和布局可能继续调整。

## 账号

打开 `/login` 登录；无账号时进入 `/register`，填写用户名、邮箱和验证码后创建账号。验证码邮件需要配置投递服务。忘记密码使用 `/forgot-password`，收到链接后在 `/reset-password` 设置新密码。登录后可在右上角菜单进入 `/profile` 修改资料、绑定安全邮箱、更新密码、退出其他设备和设置提醒偏好。

如果登录页显示“暂时无法连接”，先按[故障排查](troubleshooting.md)确认会话接口返回的是正常的匿名 401，而非依赖故障 503。

## 主要页面

| 页面 | 地址 | 主要操作 |
| --- | --- | --- |
| 招聘广场 | `/` | 浏览共享岗位目录、筛选、收藏、跳转来源或记录投递 |
| 我的投递 | `/applications` | 搜索、筛选、新建投递、编辑岗位和状态、管理招聘阶段 |
| 面经广场 | `/interviews` | 浏览公开面经、查看详情、点赞与评论 |
| 个人面经 | `/interviews/mine` | 新建和编辑私有面经，管理复盘与公开分享 |
| 求职分析 | `/analytics` | 按周期、求职类型和城市查看投递趋势、转化、面试复盘与待跟进项 |
| 提醒 | `/reminders` | 创建、修改、完成、重开、推迟和管理提醒 |
| 数据导入 | `/import` | 选择 CSV/XLSX、预检、选择有效行，再确认导入 |

投递、面经、提醒、分析和账号数据按当前登录账号隔离。公开面经和共享岗位目录有不同的可见性规则；不要在公开面经中放入不愿公开的个人信息。

## 导入、导出与重复操作

导入分为预览和确认两步。预检不等于已写入；确认前应检查字段映射、错误行、重复项和本次选中的记录。投递 CSV/XLSX 与面经导出入口以页面实际选项为准。并发或旧版本提交出现 409 时，先刷新相关记录再决定是否重试，不要反复点击确认。

## 管理员

管理员可从账号菜单进入 `/admin`，查看用户、审计和岗位市场目录/来源/候选及同步历史。普通用户即使直接输入管理员 URL 也无权调用对应 API。Java 管理界面不执行 ATS/微信采集或同步任务；同步归原版服务，Java 只读取共享数据和运行记录，并处理明确的管理审核操作。

若遇到数据不显示，先查[运行状态](operations.md)和[故障排查](troubleshooting.md)。页面显示空列表不代表应重新采集，更不能用空数据库覆盖现有数据。
