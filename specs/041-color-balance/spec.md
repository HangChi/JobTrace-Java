# 全局配色层次优化

保留当前绿色主色及主按钮、选中态的颜色，用中性背景、白色表面和少量低饱和辅助色改善单调感。

- 品牌变量 --brand / --brand-dark / --brand-soft 保持不变。
- 背景和边框转为中性灰绿，正文使用深中性色，减轻全页面泛绿。
- 灰蓝用于阶段与辅助信息，暖米色用于提醒与 Offer，失败继续使用低饱和红色。辅助色仅用于局部，不给整张页面铺多种颜色。
- 保留全部布局和行为，普通正文与辅助文本满足 4.5:1 对比度。

## 状态胶囊

投递列表、筛选及编辑表单和招聘筛选的状态下拉框统一为胶囊形；已投递/有效使用绿色，Offer/待确认使用暖金，拒绝使用淡玫红，已失效使用灰蓝，全部状态使用中性色。颜色随选择即时切换，保留原生选择、居中和提醒对齐。

状态胶囊收紧留白：列表宽度 88px，筛选/编辑状态字段宽度 128px；文字与箭头留出合理间隔，保留状态中心和提醒位置。
