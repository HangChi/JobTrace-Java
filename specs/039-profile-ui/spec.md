# 个人中心 UI 优化

个人中心采用分区切换式设置面板：个人资料、提醒设置、账号安全、数据管理、账号信息。默认显示个人资料，其余分区按需切换，保留所有既有业务流程。

- 使用同一张简洁面板，标题与表单上下衔接，移除左右说明栏与层叠卡片。手机端保持自然纵向排版。
- 切换不滚动页面、不清空未保存表单；URL hash 支持打开具体分区，未知 hash 回到个人资料。
- 原生链接保留修饰键操作；当前分区通过 aria-current 标记，隐藏面板不进入键盘与屏幕阅读器的交互范围。
- 统一资料、头像上传、提醒复选框和安全表单样式，保留邮箱、密码、设备、数据管理能力。
- 右上角显示真实头像；资料读取和上传/移除同步更新顶部，图片失败回退姓名首字。菜单采用 SVG 箭头。
- 桌面、手机、横屏均无页面横向溢出。
