# 管理员身份和后台入口
参考 JobTrace 项目的 /admin 模块，接通 Java 项目已有的运营概览、用户管理、操作审计、招聘同步和用户档案。

修复真实浏览器会话返回小写 admin/user，而 UI 使用 ADMIN/USER 的契约差异。管理员应显示管理员身份，顶部导航和账号菜单提供后台入口，个人中心同步显示身份。用户名为 admin 不构成管理员权限，未知角色不得授予管理员入口，后台接口仍由服务端鉴权。

无 returnTo 时保留服务端按角色选择的登录落点；已有管理员会话访问登录页进入 /admin。显式站内 returnTo 保持有效，外部地址继续被拒绝。普通用户直接访问后台显示无权访问。
