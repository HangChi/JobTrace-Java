# 管理后台 UI 优化
管理员后台统一采用深绿色侧栏、浅色内容区、清晰的数据卡片和操作反馈，保持 JobTrace 绿色品牌。

覆盖运营概览、用户管理、操作审计、招聘同步和用户档案。桌面侧栏常驻，平板和手机使用紧凑栏目导航。概览显示真实统计并提供常用操作快捷入口，不构造图表或趋势。用户列表优化身份层次、角色/状态标签、操作按钮和权限表单。审计记录突出操作人、对象、原因和时间。招聘管理明确说明当前能力并展示空状态。

保留现有接口、服务端鉴权、权限变更确认及审计逻辑。键盘可操作，未知/不可用数据保留占位说明，页面在 375px、768px 和 1440px 下不出现页面级横向溢出，用户表格可在容器内滚动。
