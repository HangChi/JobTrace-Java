# 紧凑运营概览与完整用户目录
概览指标过大、留白过多，改为桌面六项单行指标栏，中小屏分三列；指标卡不超过 112px 高，保留真实统计及明确标签。压缩活跃统计、快捷入口和侧栏空白。

桌面表格压缩行间距并固定表头，长用户名/邮箱允许换行；手机端改为带字段标签的用户卡片，查看档案和管理访问按钮始终保留。列表容器限高并可滚动，页面不出现横向溢出。
