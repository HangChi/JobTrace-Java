# Ant Design 式查询栏与条件面板
用户明确选择 Ant Design 式后台风格：规整搜索框、明确筛选按钮和条件面板。四页统一控件高度、边框、留白、焦点及重置图标，去掉全部条件常驻平铺。

招聘广场保留关键词搜索、地点与搜索按钮，状态/发布时间放入面板；我的投递保留关键词搜索、排序，状态/类型放入面板；面经广场保留即时公司搜索、排序，城市/岗位放入面板；求职分析保留周期与查看分析，类型/城市放入面板，自定义日期按需展开。

筛选按钮显示已选条件数量，面板支持打开/收起、关闭按钮、Esc 返回触发按钮焦点、点击外部收起、条件保留和清除。手动页面在面板应用时提交父表单；面经条件继续即时更新并提供完成按钮。移动端面板完整显示日期和选项，可滚动，不发生页面级横向溢出。
