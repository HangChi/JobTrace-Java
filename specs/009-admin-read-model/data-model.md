# Data Model: Administration Read Model

Feature 009 creates no production table or durable state. These immutable models project legacy-owned data.

## AdminSummary

- `generatedAt`: UTC instant generated by Java.
- `timeZone`: fixed `Asia/Shanghai`.
- `activityDefinition`: established explanatory copy.
- `counts`: `available` with `users`, `activeUsers`, `disabledUsers`, `administrators`, `applications`, and `interviews`, or `unavailable`.
- `activity`: `available` with 7/30-day windows and 30 daily points, or `unavailable`.

## AdminUserQuery

- `q`: optional trimmed text, maximum 100 characters.
- `role`: `all|user|admin`, default `all`.
- `status`: `all|active|disabled`, default `all`.
- `registeredFrom`, `registeredTo`: optional ISO dates; range must be ordered.
- `page`: integer >= 1, default 1.
- `limit`: integer 1..100, default 50.

## ManagedUserSummary

- Opaque `id`; display `username`; display `email`; `internalEmail`.
- `role`, `disabled`, `accessVersion`.
- `createdAt`, nullable `lastSignInAt`.
- `applicationCount`, `interviewCount`.

Display username selects display username, then username, then the internal email prefix. Display email selects recovery email, then internal email.

## ManagedUserDetail

Extends `ManagedUserSummary` with the ten newest target `recentAuditEvents`, a ten-item `applications` page, and an independent ten-item `interviews` page. Application stages, interview questions, and action items retain their legacy order. A removed linked stage falls back to the stored stage snapshot.

## AdminAuditQuery

- `actor`, `target`: optional trimmed text, maximum 100 characters; match exact ID or case-insensitive snapshot text.
- `eventType`: `all|promote_admin|demote_admin|disable_user|enable_user`.
- `outcome`: `all|succeeded|denied|conflict|failed`.
- `occurredFrom`, `occurredTo`: optional ordered ISO dates using Shanghai day boundaries.
- `page`, `limit`: same bounds as the user query.

## AdminAuditEvent

- Event and request IDs.
- Nullable actor/target IDs, immutable identifier snapshots, and derived deletion flags.
- Event type, outcome, reason, access state before, nullable access state after, nullable failure code, and creation instant.

## PageResult

- `items`, exact `total`, normalized `page`, `limit`, and `totalPages`.
- Empty results use `totalPages=0`; non-empty out-of-range requests are re-read at the last page.
