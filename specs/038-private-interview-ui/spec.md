# 个人面经界面优化

保持现有页面风格及所有数据行为。

- 修正列表六个元素与五列定义造成的错位；对齐日期、公司岗位、状态和操作。
- 手机端保留复盘状态、面试结果、公开范围，长公司岗位名可以换行。
- 编辑页以整篇面经为单位记录，保留补充行动、总结和发布设置；统一控件，修正行动复选框尺寸。
- 桌面、手机与横屏均无页面水平溢出，筛选、选择导出、编辑和保存能力不变。


## 截图反馈调整

- 收紧列表公司岗位与状态之间的留白，减少行内垂直间距。
- 详情使用岗位标题及日期轮次，主体为面试背景、面经内容、分享设置三块独立卡片。
- 面试背景四列展示日期、形式、时长和可保存的本轮结果。日期沿用关联记录，只读展示。
- 正文使用一个完整 Markdown 编辑框，支持编辑与预览切换，不显示问题编号、分类、添加或移除问题入口。旧问题与回答合并为正文，原有私有评分继续保留在私有字段中。
- 分享范围采用原生单选卡片，原复盘状态与公开身份设置保留；补充备注、行动与总结按需展开。

## 细节打磨

正文标题与编辑/预览同排，收紧标题、卡片和控件比例；编辑框默认桌面 400px、手机 340px，可纵向调整。下拉框保留箭头，补充区域和说明弱化，保存按钮作为主操作，次要操作统一收进底部操作栏。

## 编辑与预览布局稳定性

编辑和预览共用同一个可调整高度的正文框，采用一致的宽高、内边距、字体和行高，预览内容在框内滚动。切换时保持滚动进度比例，下方分享区不发生位置跳动。移除补充复盘界面，原有私有字段随保存保留，不清空旧数据。
